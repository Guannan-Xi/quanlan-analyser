# QuanLan Analyser

中文名：在线脑电分析平台

GitLab repository slug: `quanlan-analyser`

定位：面向小白用户的在线脑电数据管理、计费、分析和结果交付平台。

重要安全约束：

- 不提交真实客户脑电数据、充值记录、邮箱收件人数据或隐私数据。
- 不提交运行日志、打包结果、临时分析输出。
- 可提交前端 MVP、部署文件、示例资产生成脚本、交接文档和状态说明。

## Spike 分析模块

Spike sorting 与分析是 QLanalyser 的内部分析模块，不是第二个产品或平级项目。它面向神经电生理实验人员，优先支持本地数据读取、离线 sorting、cluster 人工审核、质量控制和常用统计分析。

模块复用现有的项目、文件、任务、报告和账户边界；不新增独立 FastAPI 服务、独立前端、独立登录、支付或客户交付链路。原始电生理数据不写入数据库，长耗时 sorting 通过统一任务/Worker 机制执行并保存参数、日志和审核结果。

首版不包含在线实时 sorting、自研 sorter、AI 自动判读、临床诊断或治疗建议。SpikeInterface、Kilosort 及具体设备格式以适配器方式逐步接入，依赖是否纳入正式环境需在真实样本验证后决定。
