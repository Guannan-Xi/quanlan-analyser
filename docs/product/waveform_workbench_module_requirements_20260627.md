# QLanalyser 独立波形展示与附件工作台需求文档

版本：2026-06-27  
分支：`feature/waveform-workbench-edfbrowser-v2`  
状态：开发基线 / 供 Codex、Claude、其他对话协作使用

## 1. 背景

当前数据准备页已经能加载教学 EEG 并显示波形，但实现仍和页面状态、项目管理、预处理表单强耦合。继续在主页面中补丁式修复，会让鼠标/键盘交互、坏段/坏道草稿、预处理设置、自动预览任务队列互相影响。

本版本改为独立开发一个小模块：`WaveformWorkbench`。模块通过明确输入输出契约运行，先在独立页面/沙盒中达到 EDFbrowser 风格交互和端到端验收，再集成回数据准备页。

## 2. 产品定位

`WaveformWorkbench` 是科研 EEG 阅片与数据准备组件，不是通用网页图表，也不是临床诊断工具。

它需要让科研用户像使用 EDFbrowser 一样完成：

1. 打开 EEG 后立即看到连续可浏览的多通道波形。
2. 使用鼠标和键盘快速浏览长时间记录。
3. 调整每页时间、振幅灵敏度、通道显示和滤波预览。
4. 在明确写入模式下标记选段、坏段、坏道，并可恢复。
5. 输出数据准备草稿或确认后的准备方案，供 PSD、TFR、ERP、PAC 等正式分析方法使用。

## 3. 参考基线

本机 EDFbrowser：

- 程序：`C:\Program Files\EDFbrowser\edfbrowser.exe`
- 手册：`C:\Program Files\EDFbrowser\manual.html`
- 官方手册：https://www.teuniz.net/edfbrowser/EDFbrowser%20manual.html

已从手册确认的核心交互：

- Timescale 控制每页显示多少秒。
- Ctrl + `+` / Ctrl + `-` 或 Ctrl + 鼠标滚轮改变 timescale。
- Amplitude 控制屏幕上全部信号的振幅/灵敏度。
- `+` / `-` 键改变全部信号振幅。
- 信号标签支持左键打开属性，并可拖动改变单信号 offset/amplitude。
- Crosshair 用于精确定位时间和标注 onset/duration。
- Annotation editor 管理标注，保存时不直接覆盖原始文件，而生成带编辑结果的副本或追加记录。

## 4. 用户故事

### U1 数据选择后立即看波形

当用户在教学模式或普通项目中选择 EEG 数据后，波形区必须自动加载当前数据。不得出现“左侧已显示当前数据，但画布仍等待选择”的状态撕裂。

验收：

- 当前数据卡片和工作台状态栏显示同一个 file id/name。
- 画布空态隐藏。
- 至少显示 1 个时间窗的真实多通道波形。

### U2 像 EDFbrowser 一样浏览

用户需要使用滚轮、键盘、时间滑块、上一页/下一页按钮连续查看 EEG。

验收：

- 普通滚轮：水平移动时间窗，不缩放。
- Ctrl/Cmd + 滚轮：以鼠标所在时间点为锚点缩放时间窗。
- PageUp/PageDown：上一页/下一页。
- Left/Right：按当前页面 1/10 小步移动。
- Home/End 或 First/Last：跳到开头/结尾。
- 快速操作不会让旧请求覆盖新时间窗。

### U3 时间尺度和振幅符合 EEG 阅片语言

用户看到的是“10 s/page”“50 uV/row”，而不是开发口径的 gain、scale、px 等内部字段。

验收：

- 时间窗控件显示 s/page 或 min/page。
- 振幅显示 uV/row。
- `+` / `-` 改变振幅灵敏度。
- Ctrl/Cmd + `+` / `-` 改变时间尺度。

### U4 浏览和写入模式分离

浏览模式下鼠标不会产生坏段、坏道或选段草稿。只有用户主动切换到选段/坏段/坏道模式后，左键拖拽或通道点击才写入 UI 草稿。

验收：

- 浏览模式下左键拖动只用于测量/十字光标/矩形缩放，不写草稿。
- 选段模式释放鼠标后生成 selected_segment 草稿。
- 坏段模式释放鼠标后生成 bad_segment 草稿。
- 坏道模式点击通道标签或通道行后生成 bad_channel 草稿。
- 草稿可恢复/撤销，保存前不写入后端 revision。

### U5 教学模式和普通模式都可用

教学模式使用内置不可删除数据；普通模式使用项目文件。两者共用同一 WaveformWorkbench，不 fork 两套交互。

验收：

- 教学数据不可删除、不可覆盖。
- 教学模式无需上传即可端到端查看波形。
- 普通模式选择文件后自动预览。
- 两者的鼠标/键盘行为一致。

## 5. P0 范围

1. 独立模块文件结构和 API 契约。
2. Canvas 多通道波形显示。
3. EDFbrowser 风格鼠标/键盘映射。
4. 事件/坏段/坏道/选段 overlay 基础绘制。
5. UI 草稿模型：选段、坏段、坏道、恢复。
6. 教学数据 E2E。
7. 普通合成 EDF/FIF E2E。
8. 与主页面集成前的稳定截图和 JSON 证据。

## 6. 非目标

本切片不做：

- 癫痫人工复核工作台。
- TimeChart 接入。
- 大文件 WebGL 重构。
- 后端路由、Headroom、gateway、IPC、model route 修改。
- 医疗诊断、自动诊断、治疗建议。

## 7. 成功标准

模块独立页面通过 E2E 后，才能集成到数据准备页。成功标准：

- 选择教学数据后 10 秒内恢复或生成波形。
- 滚动页面后波形不消失。
- 普通滚轮、Ctrl/Cmd 滚轮、PageUp/PageDown、Left/Right、+/- 均通过自动测试。
- 浏览模式不写草稿。
- 写入模式能生成可恢复草稿。
- 状态栏显示模式、时间窗、s/page、通道数、uV/row、Raw/Filter、准备方案状态。
- 输出 evidence JSON 和截图。
